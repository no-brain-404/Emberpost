# EmberPost 1.0.18

Install this entire `EmberPost` folder in the Unreal Azeroth client's `Interface/AddOns` directory.

The expected layout is:

```text
Interface/AddOns/EmberPost/EmberPost.toc
```

Fully close the client before installing or upgrading. Empty letters are preserved during Open All unless **Delete empty** is enabled.

For safety, COD supports exactly one queued item stack per send. Multi-item COD is blocked because every stack is delivered as a separate letter.

EmberPost does not claim the Escape key. Use the red **X** to close its window; Escape remains available to the game menu.

Project page: https://github.com/no-brain-404/Emberpost
